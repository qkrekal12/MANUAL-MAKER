AI 사용자 매뉴얼
자동 생성기

홈페이지 화면 이미지로 사용자 매뉴얼 제작 과정을 자동화하는 PoC
기획 범위: 제공된 기능명세 기반 · 산출물: Word(.docx) 또는 HTML(.html)
기획 요약
홈페이지 스크린샷을 분석해 화면에 보이는 메뉴·버튼·입력 항목을 식별하고, 그 정보를 바탕으로 설명과 단계별 사용 방법을 작성한다. 화면 이미지와 설명을 매뉴얼 형태로 편집해 파일로 제공하며, 사용자가 원할 때 이메일 발송을 지원한다.
01

PoC 목표

홈페이지 개발 후 사용자 매뉴얼을 제작할 때 필요한 문구 작성, 화면 구성, 디자인 및 문서 편집 업무를 자동화하고, 매뉴얼 제작에 드는 시간과 노력을 줄이는 가능성을 검증한다.

검증할 자동화 흐름

화면 이미지 업로드 → AI 화면 분석 → 사용 설명 작성 → 매뉴얼 편집 → 다운로드 → 선택적 이메일 발송

PoC 결과 범위

이미지와 기능 설명·단계별 방법을 포함한 Word 또는 HTML 매뉴얼, 그리고 이메일 발송 처리 결과 표시

02

업무 문제

매뉴얼 제작 과정에서 화면을 살펴 문구를 작성하고, 화면과 설명을 배치해 문서를 편집하는 작업이 발생한다. 이 기획의 대상은 해당 수작업을 자동화해 제작 부담을 낮추는 것이다.

AI는 이미지에서 확인 가능한 화면 요소와 동작 순서만 설명한다. 화면에 나타나지 않은 기능이나 결과를 사실처럼 생성하지 않는다.
03

주요 사용자

매뉴얼 제작자 — 홈페이지 화면 이미지를 올리고, 생성된 매뉴얼을 다운로드하거나 담당자·관련 부서에 이메일로 전달하는 사용자.

기능명세에는 별도의 사용자 역할·권한 체계가 정의되어 있지 않다.

04

05

사용자 이용 흐름

이메일 발송은 매뉴얼 생성 후 선택적으로 실행한다. 이메일을 보내지 않아도 매뉴얼을 다운로드할 수 있다.

1. 이미지 업로드홈페이지 스크린샷(PNG, JPG 등)을 등록한다. 여러 화면도 업로드할 수 있다.
2. 화면 분석AI가 주요 메뉴, 버튼, 입력 항목 및 화면 표시 정보를 분석한다.
3. 설명 작성화면에서 확인되는 구성요소와 조작 순서를 쉬운 표현으로 정리한다.
4. 매뉴얼 구성화면 이미지와 해당 설명을 읽기 편한 순서로 배치한다.
5. 파일 생성·다운로드Word 또는 HTML을 선택하고 생성된 파일을 다운로드한다.
6. 이메일 발송(선택)수신자·발신자·제목·내용을 입력하고 매뉴얼을 첨부해 발송한다. 결과를 화면에서 확인한다.

07

기대 효과

  • 문구 작성, 화면 설명 배치, 문서 편집 등 매뉴얼 제작에 필요한 시간과 노력을 줄인다.
  • 화면 이미지와 그에 대응하는 설명을 하나의 매뉴얼 파일로 구성해 다운로드할 수 있다.
  • 비개발자도 이미지 업로드부터 파일 생성까지 순서대로 이용할 수 있도록 안내한다.
  • 원할 경우 생성 파일을 담당자나 관련 부서에 이메일로 전달할 수 있다.
08

검증 항목

기능명세의 완료 기준과 예외 처리 원칙을 기준으로 PoC 동작 여부를 확인한다.

  • PNG, JPG 형식 화면을 업로드하고 주요 메뉴·버튼·입력 항목을 분석한다.
  • 화면 분석 결과로 기능 설명과 이해하기 쉬운 단계별 사용 방법을 작성한다.
  • 화면에서 확인할 수 없는 기능이나 동작을 임의로 생성하지 않는다.
  • 화면 이미지와 설명을 읽기 편하게 배치한 Word 또는 HTML 매뉴얼을 생성·다운로드한다.
  • 이메일 발신자·수신자·제목·내용을 입력하고 생성 매뉴얼을 첨부해 발송한다.
  • 이메일 발송 성공·실패 결과를 정확히 표시한다. 발송하지 않아도 다운로드가 가능하다.
  • 이미지 누락·지원하지 않는 형식·손상·인식 실패·생성 실패 시 작업을 중단하고 안내한다.
  • 이메일 입력 오류 또는 발송 실패를 성공으로 표시하지 않는다. 발송 실패 시 생성 매뉴얼은 유지한다.
