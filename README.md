# 매뉴얼 스튜디오 배포 패키지

이 패키지는 Windows PC에서 실행하는 로컬 앱입니다. 서버를 외부 인터넷에 공개하는 배포본은 아닙니다. 앱은 `127.0.0.1`에만 열립니다.

## 최초 실행

1. Node.js 20 이상(LTS)을 설치합니다. 설치할 때 npm도 포함되어 있어야 합니다.
2. `run_web.bat`를 실행합니다.
3. 처음 실행하면 `.env` 파일이 열립니다. `OPENAI_API_KEY=` 뒤에 본인이 발급받은 API 키를 입력하고 저장한 뒤 닫습니다. 키는 이 PC의 패키지 폴더에만 보관하고 다른 사람에게 공유하지 마세요.
4. 필요한 문서 라이브러리가 한 번 설치된 뒤 브라우저가 열립니다. 첫 설치 시 인터넷 연결이 필요합니다.

## 포함 기능

- 기획서 첫 페이지와 매뉴얼 스튜디오 사이 이동
- 새 화면 이미지 분석 및 파일명 숫자순 정렬
- 이미지의 버튼 위치에 번호와 설명 추가
- 화면 분석 및 사용 매뉴얼 작성
- HTML, Word, PDF 다운로드
- Outlook 계정 선택 및 매뉴얼 첨부 이메일 발송

PDF 저장에는 Microsoft Edge가 필요합니다. 이메일 발송에는 클래식 Outlook과 설정된 메일 계정이 필요합니다. 앱은 이메일을 즉시 발송하기 전에 확인을 요청합니다.

## 보안 및 배포 범위

- `.env.example`만 포함되어 있습니다. 실제 API 키를 넣은 `.env`는 배포·공유하지 마세요.
- 이미지 분석을 실행하면 첨부 이미지와 입력 메모가 OpenAI API로 전송됩니다.
- 업로드 이미지 파일은 앱에서 보관하지 않습니다.
- 이 패키지는 각 사용자의 Windows PC에서 실행하는 개인/내부용입니다. 여러 사용자가 접속하는 공개 웹 호스팅 배포본이 아닙니다.
- 실행을 종료하려면 서버 명령 창을 닫으세요.
